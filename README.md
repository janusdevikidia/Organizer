# Organizer

**Organizer** est une application web légère et compaticle mobile développée avec Flask. Elle permet de gérer vos tâches quotidiennes et vos notes avec une interface moderne en "Glassmorphism".

---

## Fonctionnalités clés

* **Algorithme Smart Score :** Vos tâches sont automatiquement triées. Les urgences et les retards remontent dynamiquement en haut de la liste.
* **Interface Responsive :** Design optimisé pour mobile avec une barre de navigation basse et des effets visuels modernes.
* **Gestion des Tâches (CRUD) :** Ajoutez, modifiez, filtrez par catégorie (Travail, Perso, etc.) et gérez les priorités.
* **Gestion des Notes :** Un espace simple pour capturer vos pensées rapidement.
* **Dates Intelligentes :** Affichage convivial des échéances (ex: "Demain", "Dans 3 jours", "Retard de 2j !").

---

## 🛠️ Installation Locale

1. Créer une web app sur Pythonanywhere en choisissant Flask et Python.

2.  **Cloner le dépôt :**
    ```bash
    git clone https://github.com/janusdevikidia/Organizer.git
    ```

3.  **Installer les dépendances :**
    ```bash
    pip install flask flask-sqlalchemy
    ```

4. Déplacer le fichier flask_app.py de ce dépôt dans /mysite

5. Reload l'App web
